- Election data: the UI imports only from `src/lib/election/live.ts`. Browsers never call the TSE (except candidate photos): the `poll-tse` Edge Function polls the TSE CDN (conditional requests, every 5s via pg_cron), stores races in Postgres (`results_latest`, `results_history`) and pushes updates on Realtime topics `res:<key>`; the `watch` Edge Function serves snapshots and marks races as watched.
- `supabase/functions/_shared/tse.ts` is pure TS shared by the Edge Functions (Deno), the app and the tests; keep it free of runtime-specific APIs. Tests use real TSE fixtures in `src/lib/election/__fixtures__/`.
- `src/lib/election/places.gen.ts` is generated by `bun scripts/gen-places.ts`.
